# Linux 驱动开发学习笔记

## 用户偏好
- 学习方式：理论学习为主，理解原理和概念
- 不需要实践练习，关注知识体系
- 已有 YU08 驱动实践经验，不需要再讲基础操作
- **教学形式：直接在终端对话教学，不使用 HTML 课程文件**
- 工作区位置：teach/ 目录，不放在 openbmc 项目根目录

## 教学策略
- 从用户已有的 YU08 驱动出发，扩展到通用知识
- 重点讲解"为什么这样设计"，而不是"怎么写代码"
- 每课一个核心概念，用对话问答检验理解
- 课程内容直接在对话中呈现，不生成 HTML 文件

## 课程规划（初步）
1. 设备模型基础（bus/device/driver）
2. probe 函数详解
3. 设备树深入
4. 内存管理（kmalloc/vmalloc/devm_）
5. 并发控制（锁、原子操作）
6. 中断处理
7. I2C/SPI 驱动框架
8. 子系统接入（hwmon/input/IIO）
9. 调试技巧
10. 驱动优化和最佳实践
